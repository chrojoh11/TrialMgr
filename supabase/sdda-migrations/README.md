# SDDA Supabase migrations

These migrations belong only to the dedicated `SDDA-Trialdesk` Supabase project
with reference `hsxwwtvzfulxdqimkgcc`.

Do not run migrations from the parent `supabase/migrations`, `previews`,
`manual`, or `rollbacks` folders against the SDDA project. Those files describe
the legacy C-WAGS database and remain temporarily for conversion reference.

Migrations in this folder are reviewed and applied in filename order only after
their SQL contract tests pass. Remote application requires a separate explicit
approval and verified connection to the approved project reference.
